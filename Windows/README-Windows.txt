文件脱敏工具（Windows x64）安装与使用说明
========================================

系统要求
--------
Windows 10 或 Windows 11，64 位系统。

安装步骤
--------
1. 将收到的 ZIP 压缩包完整解压到本地文件夹。
2. 打开 FileDesensitizer-win32-x64 文件夹。
3. 双击 FileDesensitizer.exe 启动软件。

请勿只复制 exe 文件；软件运行需要同一文件夹中的 resources、locales 等文件。

首次运行提示
------------
当前版本尚未购买 Windows 代码签名证书。若 Windows SmartScreen 显示保护提示，
请确认文件来源可信后，点击“更多信息”→“仍要运行”。

功能范围
--------
- 支持 Excel .xlsx 文件。
- 支持字段识别、选择性脱敏、生成脱敏映射表和恢复原文件。
- 当前不支持 Word、PowerPoint、旧版 .xls 文件。
- 地址默认不识别、不脱敏。

安全提醒
--------
脱敏映射表可以恢复原始信息，请与脱敏文件分开保存并妥善保管。
