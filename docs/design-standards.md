# 设计规范 — 文件脱敏工具

## 整体风格

- **简洁直观**：减少视觉噪音，每个界面只有一个核心操作
- **系统原生**：使用 macOS 原生控件，符合 Apple HIG
- **跟随系统**：自动适配 Light/Dark Mode

## 应用图标

- 主题：Excel 表格文档 + 隐私盾牌，直接表达“文件脱敏与保护”
- 主色：系统蓝/青色；敏感单元格使用少量系统橙色作为强调
- 风格：macOS 圆角方形、轻量半立体、清晰几何轮廓
- 约束：不使用文字、字母或品牌标识；缩小到 16×16 时仍能辨认盾牌与文档轮廓

## 色彩

全部使用 SwiftUI 语义色，不硬编码色值：

```
.primary          → 主文字色
.secondary        → 次要文字色
.accentColor      → 强调色（系统蓝）
.background       → 背景色
```

敏感字段标记：`.orange` （系统语义橘色）

## 字体

全部使用系统字体：

```
Font.title         → 页面标题
Font.headline      → 区块标题
Font.body          → 正文/字段名
Font.caption       → 辅助信息
Font.system(.body, design: .monospaced) → 数据值
```

## 交互流程

### 脱敏处理 Tab

```
[拖拽区域 / 选择文件按钮]
        ↓
   文件信息展示（文件名、大小、类型）
        ↓
   [Sheet选择]（仅Excel） + [字段列表]
        ↓
   [开始脱敏] 按钮
        ↓
   处理进度条
        ↓
   预览对比表格 + [保存] 按钮
```

### 数据恢复 Tab

```
[上传脱敏文件] + [上传映射表]
        ↓
   [开始恢复] 按钮
        ↓
   处理进度条
        ↓
   预览对比表格 + [保存] 按钮
```

## 布局规范

- 窗口默认大小：900×640 pt，可拉伸
- 边距：16pt（标准 padding）
- 卡片/区块间距：12pt
- 表格行高：32pt
- 拖拽区域最小高度：120pt

## 空状态

- 未上传文件时：拖拽区域显示引导文字 + 系统 SF Symbol 图标
- 无敏感字段时：字段列表为空，显示"未检测到敏感信息"

## 错误状态

- 格式不支持：红色提示 + 支持的格式列表
- 文件无法解析：提示文件可能已损坏
- 映射表不匹配：提示字段对应关系缺失
