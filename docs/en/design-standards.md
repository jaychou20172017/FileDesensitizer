# Design Standards

[中文](../design-standards.md)

Use a simple native interface with one main action per view and system light/dark adaptation. Icon: spreadsheet document plus privacy shield, blue/cyan with restrained orange sensitive-cell accents, rounded macOS geometry, no text/brand marks, recognizable at 16 px.

Use semantic primary/secondary/accent/background colors and orange sensitive markers. System title/headline/body/caption typography; monospaced values. Desensitization flow: drop/select → file details → sheet/fields → process/progress → comparison preview/save. Recovery flow: processed file + map → recover/progress → preview/save.

Default window 900×640 pt resizable, 16 pt padding, 12 pt section gap, 32 pt table rows and 120 pt minimum drop area. Empty states show guidance/SF Symbol or no-sensitive-data text. Errors distinguish unsupported formats, corrupt input and missing mapping relationships. This is a documentation translation, not a UI redesign.
