# 产品需求文档 — 文件脱敏工具 v1.0

## 项目概述

桌面文件脱敏应用，提供 macOS 与 Windows 版本。当前仅支持 Excel `.xlsx` 文件上传、字段分析、假名化脱敏、映射表生成和数据恢复。

## 核心功能

### F1 文件上传
- 拖拽或点击上传，当前版本仅支持 `.xlsx`
- `.xls` 提示先使用办公软件另存为 `.xlsx`
- Word（`.doc`/`.docx`）和 PowerPoint（`.ppt`/`.pptx`）暂不支持，选择或拖入时给出中文提示
- 展示文件名/大小/类型，单次单文件

### F2 字段分析（脱敏模式）
- **Excel**：读取所有 Sheet → 用户单选 Sheet → 列头即字段
- **敏感检测**：手机号/身份证/邮箱/银行卡/姓名/供应商名称/固话
- **地址处理**：地址不作为默认脱敏类型，不识别、不自动勾选
- **名称识别**：供应商名称支持公司全称及“供应商名称”等明确表头；正文姓名仅在高置信度人员列表中识别，避免将普通中文短语误判为姓名
- **UI**：全量字段 checkbox 列表，敏感字段橙色标记默认勾选，全选/取消全选

### F3 脱敏处理
- 假名化替换：保持格式特征，相同原值→相同替换值
- 输出：脱敏文件 + 映射表 Excel（`原名_脱敏映射表.xlsx`）

### F4 数据恢复
- 上传脱敏文件 + 映射表 → 生成恢复文件（`原名_脱敏恢复版.xxx`）
- 原脱敏文件保留不变

### F5 应用内预览
- 脱敏/恢复后以表格展示前后对比，支持滚动/翻页

### F6 保存交互
- 系统原生保存弹窗，预填默认文件名，用户选择目录
- 若目标文件已存在，确认对话框列出所有冲突文件；只有用户明确选择“覆盖”后才写入

## 文件命名规则

| 产物 | 格式 |
|------|------|
| 脱敏文件 | `原文件名_脱敏.扩展名` |
| 映射表 | `原文件名_脱敏映射表.xlsx` |
| 恢复文件 | `原文件名_脱敏恢复版.扩展名` |

## 设计决策

| 项 | 决定 |
|----|------|
| 技术栈 | SwiftUI + Swift，macOS 14+ |
| Windows 版本 | Electron，Windows 10/11 x64 |
| 脱敏方式 | 假名化替换（可逆） |
| 支持格式 | 当前仅 `.xlsx`；Word/PPT 暂停支持 |
| 字段识别 | 全量列出 + 敏感高亮推荐 |
| 恢复方式 | 生成新文件，保留脱敏文件 |
| 数据预览 | 应用内表格展示 |
| 保存方式 | 弹窗选择路径 |
| 网络 | 全程本地，无网络依赖 |
| 旧版 Excel | `.xls` 不直接解析，提示转换为 `.xlsx` |
